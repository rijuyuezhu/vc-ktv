# 网易云音乐接入（集成功能分支）

> 跟踪：[#208](https://github.com/rijuyuezhu/vc-ktv/issues/208)。本文件描述目标与尚待验证的实现路径；未完成的能力不代表生产已支持。

## 用户故事

用户除了 B 站 BV 号，还能选择网易云单曲，使用网易云标题、歌手、封面和相应歌词参与**同一场次**的点歌、排队、字幕、自动切歌和投屏。只有**全局管理员**可以连接、查看状态或断开网易云账号；本场管理员与点歌者不得获取会话凭据。没有授权音源时明确告知不能点播，不承诺整个平台曲库可用。

## 开发与合并约定

- 长期集成分支：`feat/netease-music`；专用 Worktree：`~/Playground/vc-ktv-netease-music`。普通 `main` Worktree 与生产目录相互独立。
- 每个可独立验收的小修改在**临时主题分支**完成，PR 以 `feat/netease-music` 为 **base**；测试、cold/KISS review 后 **squash merge**，删除临时分支。不要针对 `main` 开小 PR。
- 最终完成集成与验收后，可先将功能分支 rebase 到最新 `main`（此时需要考虑已发布分支的历史重写和协调），然后**普通 merge commit 到 `main`，不 squash**，保留功能分支内各次小 PR 的集成提交。
- 功能分支可以在决定试用后被单独部署，**不代表自动切换**。部署前检查正在播放/制作任务、备份与回滚能力；记录当前生产提交，确认窗口后才切换。

## 架构路径

1. **来源解析**：B 站现有解析逻辑不动；网易云支持单曲 ID、可信官方单曲 URL、`163cn.tv` 短链以及包含其中一个 URL 的完整分享文案。短链仅访问固定 `https://163cn.tv/<token>` 并验证单次 30x 跳转目标为官方单曲 URL，绝不向用户指定的任意主机发请求；歌单不支持。
2. **元信息与歌词**：搜索歌名/歌手或粘贴分享文案，返回受限数量的单曲候选结果及标题、艺术家、时长、封面，由用户选择正确版本后才点歌。元信息发现不要求网易云登录。逐句歌词暂沿用现有歌词选择流程；不能单凭同名推断与实际音频匹配。
3. **管理员登录态**：服务端通过独立二维码流程建立网易云登录态；所有管理路由使用现有 `require_global_admin()`，本场管理员与用户无法访问。参考 go-musicfox 将登录 Cookie 存入本机配置的设计，VC-KTV 在 `<VC_KTV_DATA>/.private/netease-session.json` 中仅保存 `MUSIC_U`，父目录 `0700`、文件 `0600`、写入原子替换；服务启动自动加载，重启不会清除，只有全局管理员主动断开才删除。登录可能由网易云服务端判定失效，需要重新扫码。二维码有效期约 3 分钟，二维码及凭据不写入日志、场次数据库、Git 或普通用户页面。扫码频率与风控由平台决定，**不绕过风控**。注意：该文件包含可用于访问账号的敏感 Cookie，备份与复制必须保护，不得上传公开服务。
4. **音源获取**：先在与生产隔离的环境验证公开或经许可的完整音频、音质、时长、重试、码率与失效情况。登录成功不等于可以获取任意歌曲；会员播放/下载权限也不自动授予本系统重新编码或向他人分发的权利。禁止破解 DRM、换源解锁或绕过地域/权限限制。无合法可用音源时保留明确的 unavailable 状态，不进入准备队列。
5. **统一媒体**：取得可使用音频后，合成标准 MP4，由现有字幕、队列、TV `<video>`、下载和预加载复用。来源字段与来源 ID 独立于 `bvid`，不可用伪造 BV 号的方式塞入现有表。现有 B 站数据兼容。
6. **播放器视觉**：先实现可直接用于下载及电视的 16:9 720p MP4 视觉模板，再评估额外的 HTML 动态装饰。选择下文 A 方案为基线；不要把仅能在浏览器里播放的 iframe 当成可控制的 KTV 媒体。并发制作应受 FFmpeg CPU 预算限制。

## 播放视觉方案

基础模板不是静止封面 + 黑底：

- **A. Cinematic Album Stage（首选）**：用专辑封面颜色生成渐变/大幅柔焦背景，低对比度的缓慢平移与光晕；前景放有阴影和柔和边缘高光的清晰方形封面，歌名、歌手作为克制的辅助信息。底部留出既有 ASS/HTML KTV 字幕的安全区，避免信息与歌词争夺注意力。
- **B. 唱片机舞台（备选）**：封面旁有慢速旋转的黑胶唱片及简洁光照。比 A 更具识别度，但与二次字幕、横竖屏和封面长宽比的适配更复杂。
- **C. 音频响应型视觉（后续实验）**：音频真实频谱驱动细微粒子/光环，不能用随机动画冒充实时频谱。需要单独测试每秒编码成本与闪烁/眩晕问题，非首发必备。

首版技术选择：FFmpeg 生成 1280×720 / 24fps H.264、保留原音轨或按兼容性重封装；设定峰值预算，目标适应现有默认 3 Mbps 限额，实际大小与耗时需实测。模板动效克制，保证长歌不卡顿、字幕始终清晰；封面缺失时有本地渐变兜底，不从第三方不可信 URL 直接拉取无限体积素材。不要在成片中烧入与 KTV 字幕冲突的文字。保留可下载成片的要求，而不是只做网页特效。

## go-musicfox 调研结论

[go-musicfox](https://github.com/go-musicfox/go-musicfox) 可作为登录与播放交互参考；二维码此前采用旧 `/api/...` GET，扫码后曾出现错误。现在按其公开协议结构改为 `/weapi/...` 加密 POST，并为二维码带上 `chainId`；仅使用普通 HTTP/TLS 客户端，不实现 TLS 指纹伪装或风控绕过。隔离测试已实际确认新接口成功创建二维码且未扫码时返回 `801`；**实际扫码成功 `803`、持久化 Cookie 与完整歌曲播放仍待人工验收**。

[go-musicfox](https://github.com/go-musicfox/go-musicfox) 可作为登录与播放交互参考；其主体为 GPL-3.0，VC-KTV 为 Apache-2.0，**不复制主项目实现**。它依赖的 [netease-music](https://github.com/go-musicfox/netease-music) 是另一项目，MIT 许可可单独评估，但引入 Go SDK/sidecar 增加运维复杂度。先验证是否能通过少量 Python/httpx 安全访问必需接口；遇到 462/风控如实失败，不使用绕过机制。官方外链 iframe 可作为试听/外链入口，不具备足够的父页面播放进度和 seek 控制。

## 扫码安全验证与网页登录态备用入口

用户实际扫码遇到网易云 `8821`，这是要求额外安全验证，不属于二维码超时。参考 go-musicfox（其二维码 TUI 把未识别码作为未知状态处理；新版本还支持 WebView/网页登录、Cookie 登录）以及网易云网页登录机制，VC-KTV 当前采用最小且不绕过平台验证的做法：

- `8821` 时暂停当前二维码的自动轮询，明确说明需要网易云安全验证，避免重复产生二维码导致进一步限制。原始 `MUSIC_U` 不会通过状态接口返回。
- 全局管理员可自行通过 [网易云音乐官网](https://music.163.com/) 完成正常的网页账号登录与平台要求的验证码，然后在浏览器开发者工具的 Cookies 列表复制 **`MUSIC_U` Value**，填入 **管理员 → 设置 → 网易云音乐连接 → 通过网易云网页登录态连接**；绝不把凭据粘贴到聊天、Issue 或日志中。
- 服务器仅向固定的 `https://music.163.com/api/nuser/account/get` 验证账号对象确实存在；验证通过才将单独 `MUSIC_U` 原子保存到只限服务器用户访问的私有文件中，并提供给现有 worker。验证失败不持久化、不覆盖已有登录态。
- 此备用登录不读取浏览器 Cookie、不调用第三方代登服务，也不自动解决网易云安全挑战。不要将 go-musicfox 的 GPL 实现直接复制到 Apache-2.0 项目。若网易云修改接口或账号失效，需要重新登录并导入。

## 按小 PR 逐步交付

1. [x] **Sources groundwork**：单曲 ID/官方链接的离线解析与回归测试；方案文档，不更改现有点歌功能。
2. [x] **Preview + Search + Share**：已认证的用户或管理员可搜索歌名/歌手，并识别单曲 ID、官方链接、`163cn.tv` 短链及分享文案，候选结果可点击点歌；不会包含音源 URL。逐句歌词的 song-ID 直接接入留给后续 PR。
3. [x] **Global-admin session**：二维码开始/轮询/状态/断开；持久登录 Cookie，重启恢复、文件权限、鉴权、凭据不进入响应，测试已覆盖（真实账号扫码验收仍待执行）。
4. [ ] **Media experiment**：初版仅尝试网易云普通公开播放 URL，受限或试听片段明确不可用，无绕过。已完成原创测试音频到 MP4 的合成与字幕集成；后续还需要经许可的真实音源验收、音质与下载失败测试。
5. [ ] **Visual prototype**：至少两套自制背景风格的合成视频并在电视播放尺寸验收；最终选一套后加入 worker。（已添加不依赖网络的视觉页面：[`experiments/netease-stage/`](../experiments/netease-stage/)，尚未制作真实 MP4。）
6. [ ] **Song pipeline**：已实现网易云单曲下单、来源字段迁移、标准 MP4 下载与现有字幕/队列/播放通道（原创合成音频的真实 FFmpeg 端到端测试通过）。**真实网易云完整音源尚未通过登录及实际播放验收**；UI 状态、稳定性、历史列表和音频权益需继续测试。
7. [ ] **End-to-end**：功能权限、并发、延迟、无 GPU 时间轴、投屏、缓存、音质、回滚与多设备验收。

验收必须包含：未登录/本场管理员访问网易云会话均被拒绝；音乐会话不随点歌用户泄露；扫码取消或过期后不可继续发起新下载；B 站既有测试全部保持通过；素材与账户数据不会进入公开仓库。最终合并之前重新审查许可和音频使用授权。
