# 使用指南

## 创建场次

管理员打开 `/admin/`，登录后在「设置 → 场次管理」创建场次。将加入码发给参加者；参加者在首页输入加入码，设置昵称并登录即可点歌。

## B站点歌

选择 **📺 B站**，输入 BV 号或视频链接。选择歌词来源，确认文字后提交；也可以上传 LRC，或选择不加字幕、直接使用原片。

## 网易云点歌

1. 全局管理员在「设置 → 网易云音乐连接」扫码登录网易云。登录态会保留，服务重启后可继续使用。
2. 点歌者选择 **🎵 网易云音乐**，搜索歌名或歌手，也可以粘贴分享链接或歌曲 ID。
3. 选择歌曲后确认歌词，选择「使用原时间轴」或「AI 重新对齐」。网易云歌曲使用专辑封面制作视频，和 B站歌曲进入同一个播放队列。

如果网易云要求额外安全验证，可以在官网完成登录，再按设置页面的提示通过网页登录态连接。

## 歌词与字幕

歌词候选来自 VCPedia、网易云音乐、LRCLIB 等来源。优先选择与歌曲版本一致的歌词。

- **使用原时间轴**：适合已有逐句时间戳、且与音源版本一致的歌曲；可以调整时间偏移，无需 GPU 对齐。
- **AI 重新对齐**：通过 Kim、Qwen3-ASR 和 TIFA 进行音频对齐，需要部署 GPU 模型。
- **不加字幕**：播放原片或已生成的视频。

点击队列中的歌曲可查看准备进度、更换歌词、复制来源或下载成片与原片；只能取消自己尚未开唱的歌曲。已唱歌曲可重新点歌，按普通公平队列排序。

## 管理与播放

管理员可以在管理页查看队列、置顶下一首、跳过、重唱、重新准备失败歌曲，以及调整字幕样式和在线播放码率。默认按点歌者公平轮播，可在「设置 → 点歌与队列」改为先来先唱。

在「设置 → 播放与视频」选择浏览器、电视大屏或相册播放。电视模式下打开主屏，或复制链接发送到电视；管理员可以遥控暂停、切歌、重唱与字幕。每场只有一个主屏，刷新电视页面后需重新配对。已唱歌曲可在历史中查看。

「播放与视频」可选 B站 1080p（新场次默认）、720p 或 480p，清晰度不足时自动回退；网易云封面视频固定 720p。新场次默认优先下载 AV1；原片编码也可选 H.264 或保持现状（H.265 转 H.264）。只影响新准备或上传的原片，下载原片获得处理后的版本。

电视默认使用原片叠加 HTML 字幕，可关闭；旧设备不支持 AV1 时，电视可回退烧录版。播放码率预算默认 **3 Mbps**，用于转码与电视缓存；每场媒体预算 **200 GiB**。取消尚未播放的歌曲会停止制作。
