# 使用指南

## 创建场次

管理员打开 `/admin/`，登录后在「设置 → 场次管理」创建场次。将加入码发给参加者；参加者在首页输入加入码，设置昵称并登录即可点歌。

## B站点歌

选择 **📺 B站**，输入 BV 号或视频链接。选择歌词来源，确认文字后提交；也可以上传 LRC，或选择不加字幕、直接使用原片。

## 网易云点歌

1. 全局管理员在「设置 → 网易云音乐连接」扫码登录网易云。登录态会保留，服务重启后可继续使用。
2. 点歌者选择 **🎵 网易云音乐**，搜索歌名或歌手，也可以粘贴分享链接或歌曲 ID。
3. 选择歌曲后确认歌词，选择「使用原时间轴」或「AI 重新对齐」。网易云歌曲使用专辑封面制作视频，和 B站歌曲进入同一个播放队列。

如果网易云要求额外安全验证，可以在官网完成登录，再按设置页面的提示通过网页登录态连接。

## 歌词与字幕

歌词候选来自 VCPedia、网易云音乐、LRCLIB 等来源。优先选择与歌曲版本一致的歌词。

- **使用原时间轴**：适合已有逐句时间戳、且与音源版本一致的歌曲；可以调整时间偏移，无需 GPU 对齐。
- **AI 重新对齐**：通过 Kim、Qwen3-ASR 和 TIFA 进行音频对齐，需要部署 GPU 模型。
- **不加字幕**：播放原片或已生成的视频。

点击队列中的歌曲可查看进度、更换歌词、复制来源及下载视频。可以取消自己尚未开唱的歌曲，也能将已就绪的歌曲移到个人歌单最前面，不改变其他人的演唱机会。已唱歌曲可重新点歌，按普通队列排序。

## 管理与播放

管理员队列与普通用户一样按正在播放、待播放、准备中分组，可从「歌曲记录」查看本场歌曲。管理员可以置顶下一首、跳过、重唱、重新准备失败歌曲，以及调整字幕样式和在线播放码率。默认按点歌者公平轮播，可在「设置 → 点歌与队列」改为先来先唱。

在「设置 → 播放与视频」选择播放方式。电视模式下打开主屏或将链接发送到电视，每场只有一个主屏。管理员和当前点歌者可通过各自的遥控器控制播放；伴奏就绪时可以切换原唱和伴奏。若希望等伴奏制作完成再开唱，在「点歌与队列」开启「伴奏就绪后再播放」。

「播放与视频」可选 B站 1080p（默认）、720p 或 480p，清晰度不足时自动回退。网易云使用封面合成 720p 视频。原片默认优先 AV1，旧电视建议选择 H.264。电视默认使用 HTML 字幕，不额外生成烧录版；需要下载带字幕的成片时，可开启「额外生成烧录版」。关闭 HTML 字幕或切换为非主屏播放时，未播放的 HTML-only 歌曲会自动安排烧录。播放码率预算默认 3 Mbps；原片超过预算时仍会制作电视缓存。

修改制作设置后，需要更新的待播歌曲显示更新图标，仍可播放原版本。在歌曲详情选择「更新歌曲」，或在设置中批量「更新过时歌曲」。更新期间暂缓播放，完成后恢复，失败可重试。重新点歌使用当前设置。
