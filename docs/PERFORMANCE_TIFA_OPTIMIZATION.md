# TIFA 字幕制作优化（#45）

2026-10-29，Spark-WSL。基准详情见 [BV15x411F75r 原始性能报告](PERFORMANCE_BV15x411F75r.md)。本项目仍实行 **整首字幕制作成功才允许正常播放**，没有流式字幕或成片缓存。

## 做了什么

1. **复用原歌词 TIFA 模型进程**：`align_reliable_blocks` 使用已有 `TIFASession`，让可信切点划分的全部大块、接缝局部重试与大块合并重试按原顺序使用同一已加载的 TIFA/G2P 环境；不再每块独立加载模型。ASR 识别窗口原先已在一个 worker 中批量运行，此路径保持不变。块内原生时间与越界检验仍执行。
2. **保守减少不相关的 TIFA 窗口**：保持 Qwen3-ASR **双遍 41 个短窗口识别**，但当所有歌词均为至少 3 字的中文行且某 ASR 窗口没有与歌词匹配的任意连续 2 字时，不为这段调用 TIFA 定时。其他语言、短歌词以及所有具有潜在二字锚点的窗口维持完整 TIFA。不可确认可信切点时，利用已经得到的 Qwen ASR 文本重跑**完整 TIFA 窗口定时**，绝不伪造时间信息。
3. **可诊断的模型执行耗时**：TIFA worker 额外记录模型/G2P 首次加载与逐任务 G2P、数据集准备、推理时间；只在阶段结束写入，不逐帧采样。

没有改变 Kim、Qwen 或 TIFA 模型权重、默认模型精度、原始音轨，未禁用接缝恢复，也没有新增后台常驻服务。

## A/B 完整制作测试

使用用户确认的 19 行 VCPedia 原歌词及完全相同 SHA-256 的 237.845 秒 HEVC/AAC B 站原视频，原始基准与优化版均使用 NVIDIA RTX Spark CUDA 模型/FFmpeg。每次使用独立工作目录，视频下载耗时单独计算。

| 阶段 | 原版两轮（秒） | 优化版两轮（秒） |
| --- | --- | --- |
| 提取音频 | 0.363 / 0.366 | 0.361 / 0.455 |
| Kim 分离 | 41.162 / 54.095 | 65.265 / 66.269 |
| Qwen + TIFA + 原歌词大块/接缝 | 376.439 / 362.350 | 272.115 / 277.107 |
| ASS + 补齐 | 0.042 / 0.038 | 0.036 / 0.038 |
| FFmpeg | 7.897 / 7.547 | 7.613 / 7.706 |
| **完整制作** | **426.227 / 424.703** | **345.733 / 351.608** |

两轮优化后，41 个双遍 Qwen ASR 窗口仍全部识别，仅 **36 个**需要执行 TIFA 定时（均跳过编号 0、19、20、39、40，都是不能形成原歌词锚点的窗口）。Qwen 双遍耗时 69.231 / 68.510 秒；窗口 TIFA 耗时 145.683 / 147.492 秒（原版 166.478 / 164.273 秒）。歌词仍分为原来的 6 块，接缝仍执行 `join_4_5`。

**实际收益：**原版平均 425.465 秒，优化版平均 **348.671 秒**，减少 76.794 秒，约 **18.05%**。对齐阶段均值从 369.395 降为 274.611 秒，减少 **94.784 秒（25.66%）**。注意本轮 Kim 65–66 秒，慢于历史 41–54 秒；这部分没有改动，故单纯用总耗时低估了对齐路径的收益。

质量检查不仅比较统计数：两份原版相互对照以及**两轮优化输出**，**19 行、382 个有时间戳的原生字词，逐个 ID/源文本、source span、起止时间与 timing_source 完全相同**。最长时间偏移 **0 秒**，额外估算 0，未匹配 0，接缝重试 `join_4_5` 与原音轨 AAC MD5 `a707f005f002a361ac306f475fd285ff` 一致。此前 4.73 秒短片 smoke 的 11 个原生时间戳也与金样本完全一致。

## 适用边界

更少的 TIFA 证据只允许在无中文连续二字与原词相匹配时发生。对于日语、混合语言、短歌词，或字幕可信切点不足的情况，不承诺同样加速；回退可能使该次制作更慢。对优化效果应以真实歌曲、完整歌词版本、逐字时间误差和最终播放音轨共同验收，不得只检查“生成成功”。

这一轮没有变更游客点歌/队列调度/字幕预设，也不等于生产已部署。若要继续缩短 5 分钟以上的整歌制作时间，需另行研究 TIFA 大窗口的模型推理本身与更大幅度的算法复用，并配置同质量 A/B 验收。
