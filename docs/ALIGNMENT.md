# 字幕对齐说明

生产默认 `VC_KTV_PIPELINE_MODE=global-kim`。`vc_ktv/upstream_pipeline.py` 负责抽取音频、分离、整首歌词 TIFA 对齐、字幕导出及 FFmpeg 烧录，`vc_ktv/global_alignment.py` 负责全曲对齐、发音预处理和时间轴验证。源码接口及模型环境见 [SPARK_WSL_PIPELINE.md](SPARK_WSL_PIPELINE.md)。

## 容错策略

- 优先使用 Kim 提取的人声，以减轻伴奏干扰；失败时尝试原混合音频。
- 对已知拟声词做显式读音映射，未知字母唱词先转换为近似发音，再交给 TIFA。输出字幕仍显示用户确认的歌词。
- 尽可能保留 TIFA 原生时间戳与整首歌词顺序；结果可疑时记录诊断，而不是为精度估计增加硬失败。
- 两条整首模型路径均失败时，使用最后兜底的粗时间轴并标明来源。粗时间轴只是保证歌词可显示，不代表声学准确。

在部分翻唱、长间奏和重复歌词中，整首 TIFA 仍可能出现行持续时间异常和局部错位。不要将测试通过或无漏字等同于字幕完全准确。模型输出、TextGrid、LRC、诊断和执行耗时保留在尝试归档中，以便实际听歌时核查。

`quality`、`fast` 和直接混合音频的 `global` 模式仍可用于对比，但不是生产默认模式。切换环境变量需重启服务，不属于管理员实时设置。
