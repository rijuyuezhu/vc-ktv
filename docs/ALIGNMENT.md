# 字幕对齐说明

计划恢复的默认质量方案为 `quality`：Kim 提取人声、双遍 Qwen3-ASR 对歌曲内容定位，再用 TIFA 为**全部非空识别窗口**获取原生时间信息。利用验证过的边界分块对齐用户选择的原歌词，对重复副歌和接缝做核验与必要的局部重试。

原歌词始终用于显示。PR #62 的已知拟声词（例如 `DUDUDU`、`DaLaDa`）仅在 TIFA 的 G2P 阶段替换读音；普通英语不被擅自改写。质量模式不得因为 ASR 窗口缺乏连续二字歌词匹配就跳过 TIFA。

保留 #47 中复用已加载的 TIFA 模型进程的基础设施优化；不使用 Fast Mode 的 Kim 省略、ASR 窗口 TIFA 省略、粗切块等算法捷径。模型对齐失败要留下诊断，保留完整歌词的估计字幕作为最终回退；不能声称粗估时间轴等价于真实对齐。切块时长仅作为优化目标，不能作为硬终止条件。

旧的 `global-kim` 整首 TIFA 模式仍可显式选择用于对比，但不作为恢复版默认值。模型、运行时与原始尝试材料参见 [SPARK_WSL_PIPELINE.md](SPARK_WSL_PIPELINE.md)。
