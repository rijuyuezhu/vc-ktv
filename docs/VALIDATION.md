# 验证与质量边界

本文件只保留对项目维护有用的、可公开复述的验证结论，不记录部署机器、私人网络地址、真实点歌记录或个人文件路径。

## 自动化验证

- Python 3.12 环境下，pytest 覆盖管理员认证、普通用户点歌权限、队列公平性、下载失败重试、歌词搜索与选择、媒体签名访问、TIFA TextGrid 解析，以及 TV 连播状态变更。
- GitHub Actions 从 uv.lock 安装依赖，运行 pre-commit、pytest、FFmpeg 媒体处理测试、Shell 与 JavaScript 语法检查。
- 单元测试使用独立临时数据库与合成示例视频，不访问生产库；无需下载模型权重或运行 CUDA。

## 媒体验证

- 在配有 NVIDIA GPU 的 Linux 测试环境中，曾成功执行官方 TIFA 声学对齐模型，生成 TextGrid，再由应用生成增强 LRC、ASS 字幕和 MP4 成片。
- FFmpeg/libass 转码、生成的 H.264/AAC 视频，以及播放器的单次启动后自动切歌行为，已在测试环境做过验证。
- 针对 yt-dlp 提取页面失败的公开媒体，曾验证 B 站公开播放接口的后备 H.264/AAC 下载路径。
- 歌词来源和对齐时间可能不匹配实际翻唱录音；模型内部置信指标不等于人工标注的准确率。

## 未完成的验收

- 没有对真实包厢或 Android 乐播 SDK 接收端完成端到端验证；目前仅支持网页播放/屏幕镜像。
- 尚无足够带授权、具有人工逐字时间标注的真实 VC 歌曲测试集，不能声明词级对齐质量达到生产标准。
- CI 不进行真实 B 站媒体获取、CUDA GPU 推理、线上私有网络通信或真实设备投屏。
- 对外开放前需要 HTTPS、房间权限、全面限流和资源配额；详情见 SECURITY.md。

声学实验与可选依赖的细节另见 ALIGNMENT.md；当前行为参见 AUTOPREP.md。
