# 网易云封面舞台：纯视觉实验

用浏览器直接打开 [index.html](index.html)。无需登录、外部素材、在线接口和构建工具。点击右上角可在 **氛围封面** 和 **黑胶舞台** 之间切换。

本实验使用原创抽象模拟封面、假歌名、假歌词与装饰性动效；**不播放音乐，不实现音频响应，不提供可下载视频**。后续验证的是将合法取得的音频和专辑封面变成可供电视播放及下载的标准 MP4，不能简单拿浏览器画面代替已交付的媒体生成器。

## 视觉意图

- 左侧有立体感的清晰封面，右侧歌名与歌手，后方是柔焦渐变、缓慢移动的光晕，避免“黑底 + 静止图片”。
- 另一款采用黑胶唱片与低调反光，适合较复古的曲目。最终只保留验证后成本、兼容性、辨识度更合适的一套或少量风格预设。
- **最重要的是字幕**：底部为既有 KTV 字幕预留区域，歌词不会被封面、进度条或烟雾遮挡。实际字幕仍沿用现有 ASS / HTML 时间轴和位置配置。
- 编码目标：720p / H.264，尽量复用既有码率上限和播放器，不引入运行时 Chromium 依赖。动画效果及编码速度均待 FFmpeg 合成实验实测。
- 页面会遵守 `prefers-reduced-motion`。装饰性均衡器不代表真实频谱，实际产品应去掉或连接真实音频分析结果。

## 独立验收

浏览器 1280×720、16:9、大屏与窄屏测试；不从外部下载资源。真实音源、字幕同步、CPU 编码成本、输出文件大小和无 GPU 路径 **尚未验收**。
